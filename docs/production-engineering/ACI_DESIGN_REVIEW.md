# Agent-computer interfaces

The individual ACI tool validates a flat object-schema profile and sample arguments; it rejects boolean values where the integer type is declared and exposes missing required definitions. It does not silently accept unsupported schema constructs. The catalog helper starts from a host-classified intent, intersects it with allowed tool IDs, and selects serialized contracts within an exact byte budget.

The runtime demo validates an entire typed plan before fake callbacks run. Authorization and effect enforcement belong to the host. For deployment, compare baseline and treatment using a fixed tool-selection corpus: exact selection, valid-argument fraction, success after recoverable errors, and billed input tokens. Report exposure bytes separately from tokenizer or billing measurements. This repo runs synthetic controls only.
