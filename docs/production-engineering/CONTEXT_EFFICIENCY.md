# Context and inference efficiency

The prefix fixture matched one stable segment under key reordering; moving the dynamic segment first produced zero stable segments. Supplied fixture cache usage (60 / 100 input tokens) is kept distinct from the local byte proxy. The compaction fixture detects lost offline constraints, dropped errors and changed artifact bytes. A restored checkpoint is not authority to perform a side effect.

The serving fixture models 65,536 KV bytes per token per GPU, rounds 17 tokens to a 32-token allocation and fits at most three concurrent sequences given its declared headroom. This is arithmetic for conventional KV sharding, not a measured throughput result. When hardware is authorized, replay identical cold/warm workloads across colocated and disaggregated pools; retain TTFT, intertoken latency, goodput, utilization, cache evictions and handoff metrics.
