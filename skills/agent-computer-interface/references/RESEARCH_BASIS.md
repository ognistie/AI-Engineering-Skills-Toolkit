# Research basis

Primary reference: [SWE-agent and Anthropic tool design (2024–2025)](https://www.anthropic.com/research/writing-tools-for-agents).

ACI treats tool affordances as part of the agent system. Anthropic demonstrates iterative tool design and eval; SWE-agent studies interface design in software tasks. This linter tests a flat supported schema profile, not constrained decoding or model tool accuracy.
