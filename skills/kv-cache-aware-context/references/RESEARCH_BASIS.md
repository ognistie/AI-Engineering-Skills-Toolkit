# Research basis

Primary reference: [Manus, Context Engineering for AI Agents (2025)](https://manus.im/en/blog/Context-Engineering-for-AI-Agents-Lessons-from-Building-Manus).

Manus describes stable prompt prefixes, append-only history and consistent tools as ways to improve cache reuse in its system. The helper compares deterministic bytes and keeps provider usage separate; byte overlap is not token overlap or billing.
